Connect to Firebase

The current connection isn't working, so you can replace it without signing in.
Firebase Console → Project settings (gear icon) → Your apps → your web app → SDK setup and configuration → Config. Copy the whole block.
Check or type each value
Database
Paste google-apps-script/Database.gs into a Google Sheet (Extensions → Apps Script), set its FIREBASE_API_KEY, deploy it as a Web app (Execute as: Me, Access: Anyone), and paste the URL here. Each action takes about 1 to 3 seconds with Google Sheets.
In Supabase: run supabase/schema.sql in the SQL Editor, add Firebase under Authentication → Third-party Auth, then copy the Project URL and publishable key from Project Settings → API Keys. Never use the secret or service_role key.
Last step (one time):
  1. Put the downloaded firebase-config.js into the project's js folder, replacing the old one.
  2. Push it: git add js/firebase-config.js, git commit -m "School connection", git push.
  3. After about a minute, open the website again (Ctrl + F5). Every device now connects automatically.
