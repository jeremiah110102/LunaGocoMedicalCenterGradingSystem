When someone signs in while their account is open on another device, the system asks whether to sign out the other device and continue on the new one. The other device is then signed out automatically.

Counts time without clicks, typing, scrolling or touches. A warning with a Stay signed in button appears shortly before.

Teacher downtime

Loading…

Closes grade entry for teacher accounts only: they can still sign in and view their classes and grades, but can't enter grades or send change requests. Administrators and registrars keep full access. The database refuses teachers' grades during downtime, not just the screen.

Leave empty to keep it closed until you turn it off.

Email sending (EmailJS)

Checking…

With EmailJS set up, final grade reports are sent directly from the system, including a whole section at once. Without it, reports open in each person's own email app.

Fill in all three, or leave all empty to turn direct sending off. Setup steps are in the README under "Emailing reports". Stored in Firebase; only administrators and registrars can read them.

Google Sheets copy

Checking…

Keep a copy of every record in a Google Sheet you own, one tab per list. It's a one-way copy: Firebase stays the real database. Unlock to set it up or change it.

  1. Create a Google Sheet, open Extensions → Apps Script, and paste the file google-apps-script/SheetsCopy.gs from the project.
  2. In that file, change SYNC_KEY to your own long secret, save, then Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone).
  3. Paste the Web app URL and the same sync key here, then Test and Save.

Use a Google Sheet as the school's database

Where do I get this URL?
  1. Open your Google Sheet → Extensions → Apps Script, and paste google-apps-script/Database.gs.
  2. Set FIREBASE_API_KEY to your Firebase apiKey and save.
  3. Deploy → New deployment → Web app: Execute as Me, Who has access Anyone.
  4. Copy the Web app URL (ends with /exec) and paste it above.
This changes the database for every account and device. They follow automatically within about a minute. If you have data, download a full backup first (Backup and restore). After switching you'll be signed out. If the Sheet is empty, the sign-in page asks you to create the administrator: use your existing username and password, then Import all your backup.

Use Supabase as the school's database

This key is meant for websites. Never paste the secret or service_role key.
How do I set up Supabase?
  1. Create a project at supabase.com.
  2. SQL Editor → New query: paste supabase/schema.sql from the project and click Run.
  3. Authentication → Sign In / Providers → Third-party Auth → Add provider → Firebase, and enter your Firebase Project ID ().
  4. Project Settings → API Keys: copy the Project URL and the publishable key, and paste them above.
This changes the database for every account and device. They follow automatically within about a minute. If you have data, download a full backup first (Backup and restore). After switching you'll be signed out. If Supabase is empty, the sign-in page asks you to create the administrator: use your existing username and password, then Import all your backup.
